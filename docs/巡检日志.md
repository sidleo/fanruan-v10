# 巡检日志（fanruan-v10 / frcli）

每轮巡检（含手动补跑）收尾**追加一行**。用途：① 发现漏跑/断档（先看最后一行日期）；② 发布追溯。

只记录**计数、结论、版本/提交号**。不写真实报表名、人名、工号、域名、组织、客户数据——本仓库可能公开。
详细证据留在会话里，或写进知识库（环境/口径类），不进本仓库。

## 约定

- 日期 = 本轮运行日（本地 Asia/Shanghai）；「扫描窗口」= 实际覆盖的会话时间窗。
- 结论列格式：`无改动` / `改：<一句话>`；版本列写 `0.10.x / <commit>`，未发布写 `—`。
- **开头自检**：最后一条日期若不是「昨天」，说明有漏跑 —— 报告里必须显式列出缺的日期，并先补扫缺口（`--days N`）。
- 漏跑本身也记一行，原因写清楚（这是唯一能事后发现「任务停摆」的落盘痕迹）。
