# 内容落点判定（skill 仓库 / 本地知识库 / 机器本地状态）

> 一条知识该写进本仓库、写进本地知识库（llm-wiki），还是**根本不进任何文档**（机器本地状态）。
> 本仓库可能公开，所以判定看「跨环境是否成立 + 是否含真实标识」，不按主题习惯。
> 与 `docs/发布与脱敏.md` 配套：那里讲怎么脱敏，这里讲**为什么这条不该进仓库**。

## 三抽屉

| 抽屉 | 放什么 | 载体 |
|---|---|---|
| **skill 仓库** | 工具能力/契约：命令、参数、平台通用行为、错误分类、版本门禁、发布与回归规范 | 本仓库（会打包进 skill） |
| **本地知识库（llm-wiki）** | 环境事实、真实资产、业务口径、判断类经验、实测数值 | llm-wiki 对应分类 |
| **机器本地状态** | 自动化任务提示词与绑定、实例配置与 token、profile 配置、黑名单文件 | `~/.dsh`、`~/.frcli`、profile 目录，**不进任何文档** |

## 四问定落点

| 问题 | 是 → | 否 → |
|---|---|---|
| 1. 换台机器 / 换实例 / 换账号还成立？ | 进第 2 问 | 知识库（或机器本地状态） |
| 2. 公开到仓库会暴露真实人名/域名/报表/组织？ | 能改占位符 → 仓库；不能 → 知识库 | 仓库 |
| 3. 读者是「用 CLI 的人/agent」？ | 仓库 | 知识库 |
| 4. 会随工具版本变化？ | 仓库（加版本门禁/条件式兼容提示） | 随业务/环境变化 → 知识库（带时效） |

## 默认进仓库

- 命令树、参数、必填项、危险等级与安全红线。
- 平台**通用行为**：出错页两种选择器、内存保护页、11300002、模板锁、远程设计协议、各超时变量的语义。
- 报错原文 → 处置动作的故障排查表；传输错误三分（超时 / 对端重置 / 本机代理）。
- 版本门禁与条件式兼容提示（`<x.y 会怎样`）。
- 写模板的方法论与 XML 配方；示例一律用 `demo_group/...`、`demo_conn` 等占位符。
- 发布流程、脱敏门禁、测试与回归规范（"新测试要有牙"）。
- 巡检台账（`docs/巡检日志.md`）：工具自身的维护记录，只写计数/结论/版本与提交号。

## 默认进知识库

| 类型 | 例子 |
|---|---|
| 环境事实 | 本机 / 服务器、实例地址、账号、域名、代理与 fake-IP、安装路径 |
| 业务口径与 SQL | 指标口径、取数源优先级、表结构与 join 陷阱 |
| 组织与职责 | 品类/区域架构、个人负责范围 |
| 真实资产 | 生产报表的路径、参数、推送链路、真实模板结构 |
| 实测数值与日期 | 某模板冷启动/缓存耗时、某导出的数值抖动 |
| 判断类经验 | "为什么这个错是平台保护而不是格式问题"、"怎么区分 reset 与超时" |
| 用户偏好 | 报表样式、结构偏好 |

## 灰区裁决

| 内容 | 落点 | 形态 |
|---|---|---|
| 平台通用行为（内存保护页、模板锁、11300002…） | **两边都有** | 仓库：命令级判据与处置；知识库：现象、业务影响、本环境实测值。互相引用，不整段复制 |
| 本机网络/代理故障 | 知识库为主 | 仓库只留通用机制（失败在代理这一跳、不自动绕过）；具体环境怎么绕行走知识库 |
| 某次真实事故的现场（真实报表名/账号/时间） | 知识库或会话 | 仓库只收脱敏后的通用判据 + 回归测试（fixture 用占位符） |
| 报表创作配方（cpt 怎么写） | 仓库 | 示例占位符化 |
| 某张生产 cpt 的真实参数/数据集/推送配置 | 知识库 | 不进仓库 |
| 自动化任务提示词（含测试目录、写范围等真实值） | 机器本地状态 | 不写文档；方法论可写脱敏版 |
| "本机当前装的是 x.y" | 不写或知识库带日期 | 仓库只写"≥x.y 怎样" |
| 命令参数反直觉、错误提示不给建议 | 仓库 | 属命令契约，改代码或进故障排查表 |

## 双写与冲突约定

1. 两边都有的内容做**形态分工**：仓库写"命令怎么用、判据是什么"；知识库写"为什么、在本环境怎么判断、真实值多少"。
2. 冲突时以**线上实测**为准，同一轮两边一起改；知识库引用命令名，不整段复制 help。
3. 不要在两处写同一段话：仓库里出现真实标识是红线；知识库里复制命令树会随版本过期。
4. 每次发布后核对知识库里三条与版本相关的提示（超时、兼容、坑点）是否需要同步改；知识库发现"平台行为变了"，反向提给仓库改判据。

## 两个可执行的自测

- **公开测试**：把这段贴到一个陌生公司的公开仓库，会不会暴露你的服务器/账号/报表？会 → 知识库；不会但能帮助任何人正确使用 CLI → 仓库。
- **失效测试**：删掉这段会让**所有用户**用错工具吗？会 → 必须进仓库（带测试）；只会让**你**少一条本地知识 → 知识库。
