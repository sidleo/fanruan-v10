## 1. 两条最重要的发现（先看这个）

### 1.1 层次坐标**函数族是语法糖**，方括号才是原语

`com.fr.function.AbstractHAFunction`（`fine-report-engine-10.0.jar`）：

```java
public abstract class AbstractHAFunction extends AbstractFunction implements NodeStrTransfer {
    public Function.Type getType() { return Function.HA; }        // HA = 层次坐标（Hierarchical Address）
    protected abstract String initFormula(Object[] args);
    protected String getFormula(Object[] args) { ... this.formula = this.initFormula(args); ... }
    public String exString(String s, Node[] n, CalculatorProvider c) {   // 把自己「重写」成方括号公式
        Expression e = c.parse(this.getFormula(n));  return e.exString(c);
    }
}
```

⇒ **`MOM/CIRCULAR/LAYERTOTAL/CROSSLAYERTOTAL/HIERARCHY/PROPORTION/SORT` 每个都会先把自己展开成
`Cell[坐标]` 形式的公式，再交给公式引擎求值。**
**所以：方括号是底层能力，这 7 个函数是糖。** 实现时要么把方括号做对（函数自然就对），
要么把 7 个函数按下面的展开式硬编码（也能对，但覆盖面窄）。

### 1.2 `!0` 是一个**词法记号**，不是 `!` 加 `0`

`com.fr.parser.FRLexer.mALLL()`：

```java
public final void mALLL(boolean bl) { ... this.match('!'); this.match('0'); ... }   // 连吃两个字符 "!0"
```

`FRParserTokenTypes.txt` 里 `ALLL=35`，紧接着 `ALLL2=36` —— 而 `mALLL2()` 匹配的是 **`` `0 ``（反引号+0）**，
即**老写法**。所以 `[!0]` 整体是一个 token，`!` 单独并不构成"倒序/非"之类的前缀。

同类 token（`FRParserTokenTypes.txt`，ANTLR 2.7.7 生成）：
`LBRACK=29` `[`、`RBRACK=31` `]`、`SEMI=30` `;`、`COLON=28` `:`、`COMMA=25` `,`、
`LCURLY=32`/`RCURLY=33` `{`…`}`、`WAVE=27` `~`、`SHARP=41` `#`、`AT=42` `@`、`CR_ADRESS=40`（单元格地址）。
（`AtomColumnIndex.toString()` = `"#"+n`、`AtomLayerIndex.toString()` = `"@"+n` —— 这是**解析器内部**形态，
不是你能在模板里写的语法。）

## 2. 语法分解（每种写法 + 出处）

### 2.1 总表

| 写法 | 语义 | 依据 |
|---|---|---|
| `A3[!0]` | **该格扩展出来的全部单元格**（数组） | 🔵 FR 帮助：`PROPORTION(A1)` ≡ `A1/sum(A1[!0])`；`AbstractHAFunction` 展开式 |
| `A3[;!0]` | **横向**那一维的全部 | 🔵 FR 帮助：`HIERARCHY(A1,B1,-2,false)` ≡ `B1[;A1:-1]`（横向展开时坐标前多一个 `;`） |
| `A3[!0;!0]` | **两个维度**的全部（交叉表整块） | 🟡 语料 14 处 / 8 模板：`count(C4[!0;!0]A{C4 > $C4 && A4 = $A4}) + 1`；🔵 `CROSSLAYERTOTAL` 展开里出现 `D1[A1:-1,B1:!-1]` |
| `A3[A3:-1]` | **相对**：A3 的**上一个** | 🔵 帮助：`LAYERTOTAL(B1,C1,D1)` ≡ `D1[B1:-1] + C1`；`MOM(A1,B1)` ≡ `IF(&A1>1, B1/B1[A1:-1], 0)` |
| `A3[A3:+1]` | **相对**：**下一个**（`+` 可省） | 🟡 `doc/Advanced/Coordinate/交叉表相对层次坐标.cpt`：`=B2[A2:+1 ;B1:2]A` |
| `A3[A3:1]` | **绝对**：第 1 个 | 🟡 同上：`=B2[A2:1 ;B1:-1]A`；`=B2[A2:4;B1:2]A` |
| `A3[A3:!-1]` | **从末尾数**第 1 个（=最后一个） | 🔴 **推测待验证**：语料仅 `交叉表绝对层次坐标.cpt` 一处（`=B2[A2:!-1;B1:!-1]A`），模板名自称"绝对层次坐标"；与 `!0`=全部 的类比是猜的 |
| `&A3` | 该格**当前扩展出的序号**（从 1 起） | 🔵 `MOM` 展开式 `IF(&A1 > 1, ...)` —— 用它跳过第一行；🟡 语料 67 处 / 56 模板 |
| `$A3` | **当前坐标位置上** A3 的值（用于条件里跟自己比） | 🔵 帮助：`SORT(A1)` ≡ `COUNT(A1[!0]{A1 > $A1}) + 1`；🟡 语料 24 处 / 18 模板 |
| `A3[!0]A{条件}` | 坐标取到的**数组**再按 `{…}` **过滤**；支持 `&&` `\|\|`、字符串、`$X`、`&X` | 🟡 语料 **32 处 / 24 模板**（本节最常用形态！）；🔵 `SORT` 帮助里有 `{A1 > $A1}` |
| `A3[!0]A` 末尾的 `A` | **取数组**（不加时按单值处理） | 🔴 **推测待验证** —— 见 §2.3 |
| `[A2]A` / `["a","b"]A` / `[E107,E108]A` | **数组字面量**后同样跟 `A` | 🟡 语料：`JOINARRAY([A2]A, "")`、`=["用户","用户名称",…]A`、`=[E107,E108,…]A` |
| `A3[!0]{条件}`（**不加 `A`**） | 帮助文档里这么写，语料里**0 处** | 🔵 帮助 vs 🟡 语料为 0 —— 见 §2.3 |

### 2.2 分隔符：`;` 与 `,` 都能分隔两维，但分工**没查清**

语料里三种都出现：
- `=B2[A2:-1 ;B1:1]A`（`;`，`doc/Advanced/Coordinate/交叉表相对层次坐标.cpt`）
- `= if (&A4>1,C4 / C4[A4:-1,B4:+0]A,'--')`（`,`，`demo/basic/同比环比等财务统计表.cpt`）
- `B1[;B1:-1]A`（**开头**就是 `;`，`doc/Advanced/Coordinate/HIERARCHY横向扩展.cpt`）

**能确定的**（🔵 FR 帮助原文）：
> 「公式中最后一个参数表示横纵向, 默认不传递, 表示纵向扩展, 若横向扩展, 则需要加上最后一个参数 FALSE 来区分.
>  若为横向, 偏移量为 -2, 则写成 `HIERARCHY(A1, B1, -2, false)`, 等同于 `=B1[;A1:-1]`.」

⇒ **坐标开头多一个 `;` = 横向维度**；不带 = 纵向维度。

**不能确定的**（🔴）：`[A4:-1,B4:+0]` 用 `,`、`[A2:-1 ;B1:1]` 用 `;`，两者是否等价、
还是 `;`=横向维度的分隔而 `,`=同层追加 —— **FR 的展开式里两种都用**（`CROSSLAYERTOTAL` 展开用 `,`、
`HIERARCHY` 展开用 `;`），语料也没有反例能区分。**要用就照抄语料里同名场景的写法。**

### 2.3 末尾那个 `A` 是什么（诚实结论：**没查清**）

**事实**（🟡 语料 56 处 / 18 模板，`]` 后紧跟 `A`）：
- `=JOINARRAY([A2]A, "")` —— `[A2]` 后跟 `A`
- `=["用户","用户名称","联系电话",…]A` —— 字符串数组后跟 `A`
- `=B2[;!0]A{B1 = "孙林"} / C2` —— 坐标后跟 `A` **再跟条件**
- `=COUNT(C2[!0]A{A2 = $A2 && C2 > 2500})` —— 同上

**推断**（🔴）：`A` 是**后缀运算符"取数组"**；坐标可能匹配多个格子时必须加，不加则按单值处理。
**但 FR 自己的帮助里 `PROPORTION` 写作 `A1/sum(A1[!0])`、`SORT` 写作 `COUNT(A1[!0]{A1 > $A1}) + 1`，
都不带 `A`** —— 说明 `A` 要么可省，要么帮助文档写的是简写形式。
**实现建议：照抄语料（带 `A`），别照抄帮助文档（不带 `A`）。**

## 3. 术语与函数：一张「我要 X → 怎么写」表

**数据来源**：FR 自带帮助原文（`core_zh.properties`，🔵）＋ `AbstractHAFunction` 各子类 `initFormula` 展开式（🔵）
＋ 语料真实片段（🟡）。**每一行的"等价写法"都是从 jar 里读出来的，不是猜的。**

| 我要的效果 | 函数写法 | 等价的原生坐标写法 | 语料频次 |
|---|---|---|---|
| **环比**（本月/上月） | `=MOM(A4, C4)` | `=IF(&A4 > 1, C4 / C4[A4:-1], 0)` | 2 处 / 2 模板 |
| **占比**（本值/该列合计） | `=PROPORTION(B2)` | `=B2 / sum(B2[!0])` | 1 处 / 1 模板 |
| **排名**（降序，默认） | `=SORT(A1)` | `=COUNT(A1[!0]{A1 > $A1}) + 1` | 3 处 / 3 模板 |
| **排名**（升序） | `=SORT(A1, false)` | `=COUNT(A1[!0]{A1 < $A1}) + 1` | — |
| **逐层累计** | `=LAYERTOTAL(B1, C1, D1)` | `=D1[B1:-1] + C1` | 2 处 / 2 模板 |
| **跨层累计**（每年重新起算） | `=CROSSLAYERTOTAL(A1, B1, C1, D1)` | `=IF(&B1 > 1, D1[B1:-1] + C1, D1[A1:-1,B1:!-1] + C1)` | 1 处 / 1 模板 |
| **循环引用累计** | `=CIRCULAR(A1, B1, C1, D1)` | `=IF(&A1 = 1, 0, B1[A1:-1] + C1[A1:-1] – D1[A1:-1])` | 2 处 / 2 模板 |
| **层次坐标简写**（取上一个） | `=HIERARCHY(A1)` | `=A1[A1:-1]`；`=HIERARCHY(A1, B1)` ≡ `=B1[A1:-1]` | 9 处 / 5 模板 |
| 上面 6 个函数要**横向** | 末尾加 `false` | 坐标前多一个 `;`：`B1[;A1:-1]` | — |

> ⚠️ **SORT 的默认升降序，FR 自己的三份帮助互相打架**（🔵 原文）：
> 中文 `core_zh.properties`：**「默认降序排列, 如需要升序, 则传递参数 false」**（且与它的公式自洽：
> `{A1 > $A1}` 数"比我大的" → 降序）
> 英文 `core_en.properties`：**"the default is ascending order. If you need descending order, pass the parameter false"**
> 繁体 `core_zh_TW.properties`：**「預設升序排列」**
> ⇒ **以中文帮助为准（默认降序）**，但**请实测确认** —— 这是"文档自相矛盾"，不是笔误级别的问题。

> ⚠️ `HIERARCHY` 的帮助原文还写着「若为横向, **偏移量为 -2**, 则写成 `HIERARCHY(A1, B1, -2, false)`,
> 等同于 `=B1[;A1:-1]`」—— 传 `-2` 却展开成 `-1`，**帮助自身也不自洽**（🔵 原文如此，未验证真机行为）。

## 4. 最值得照抄的那一个模板：`demo/basic/同比环比等财务统计表.cpt`

**这是全库唯一一张把「环比 / 同比 / 占比 / 排名 / 累计」五件事一次讲完的官方模板**
（24170 字节，自带中文说明文字：「FR 中使用层次坐标公式可以轻松实现环比、同期比、累计、排名等财务统计表」）。
逐格读出（🟡 直接从模板字节解析）：

```
A3=年份  B3=月份  C3=销售额  D3=月份环比  F3=年份同比  H3=占比
I3=年内排名  J3=总排名  K3=年内累计  （L3=总累计，同 K 之后一列）

A4=$$$（年份，纵向扩展）  B4=1（月份，纵向扩展）  C4=0（销售额）
C5 = =sum(C4)                                    ← 合计格，被 H4 引用

D4（月份环比）= if(&B4 > 1 , C4 / C4[B4:-1]A , '--')
F4（年份同比）= if (&A4>1,C4 / C4[A4:-1,B4:+0]A,'--')
H4（占比）    = C4 / C5
I4（年内排名）= count(C4[!0;!0]A{C4 > $C4 && A4 = $A4}) + 1
J4（总排名）  = count(C4[!0;!0]A{C4 > $C4}) + 1
K4（年内累计）= K4[B4:-1]A + C4
L4（总累计）  = if(&B4 > 1, L4[B4:-1]A, L4[A4:-1,B4:!-1]A) + C4
```

**逐条读法**（这是本文件最值钱的一段）：

| 效果 | 关键技巧 |
|---|---|
| **环比** D4 | `C4[B4:-1]` = 同一"月份"维度上的**上一个**；`&B4 > 1` 保证**第一个月不出数**（否则取到空）→ 用 `IF(... , '--')` 兜底 |
| **同比** F4 | `C4[A4:-1,B4:+0]` = **上一年 + 同一月**（两个维度同时定位）；`&A4>1` 保证第一年不出数 |
| **占比** H4 | `C4 / C5`，C5 是合计格 `=sum(C4)`；**FR 帮助给的通用式是 `PROPORTION(A1) ≡ A1/sum(A1[!0])`**，两者等价关系取决于 C5 的作用域（🟡 未验证） |
| **分组内排名** I4 | `C4[!0;!0]A{C4 > $C4 && A4 = $A4}` = 全部数据里、**同一年**的、比我大的有几个 → +1 = 名次；`$C4` = 当前值，`$A4` = 当前年份 |
| **总排名** J4 | 去掉 `A4=$A4` 条件即可（只留 `C4 > $C4`） |
| **年内累计** K4 | `K4[B4:-1]A + C4` = **自己上一行 + 本行**（自引用 + 层次坐标） |
| **跨层累计** L4 | `IF(&B4>1, L4[B4:-1]A, L4[A4:-1,B4:!-1]A) + C4` = 年内用上一月；**每年第一个月**用"上一年的最后一月"（`B4:!-1` 从末尾数） |

**同一张表用函数写就变成**：`=MOM(A4,C4)` / `=PROPORTION(C4)` / `=SORT(C4)` / `=LAYERTOTAL(B4,C4,K4)` /
`=CROSSLAYERTOTAL(A4,B4,C4,L4)` —— 一比就知道函数是糖。

## 6. 已知静默错形态（**这一节直接决定验收怎么做**）

| # | 写法 | 看着像 | 实际是 | 依据 |
|---|---|---|---|---|
| 1 | `C3`（裸格引用，不带坐标） | "取 C3 整列" | **只取当前行**的 C3（在本格所在的那一组里） —— 扩展报表里几乎肯定不是你要的 | 🟢 本项目已实测（team 结论） |
| 2 | `C3[!0]` | "取 C3 这一格" | **C3 扩展出来的全部格子**（数组；求和/计数要的就是它） | 🔵 FR 帮助 `PROPORTION(A1) ≡ A1/sum(A1[!0])` |
| 3 | `sum(C4)` 不带坐标 | "整列合计" | 只求**当前扩展作用域**内 —— 在 `同比环比等财务统计表.cpt` 里它是被 `C5` 用作合计格；换个位置含义就变 | 🟡 语料用法 |
| 4 | `&A3` 用在第一行 | "上一行" | `&A3` = 当前序号；**第一行时 `&A3 = 1`**，`A3[A3:-1]` 会取到**空**，除非像语料那样 `IF(&B4>1, …, '--')` 兜底 | 🔵 `MOM` 展开式 + 🟡 语料 F4/D4 |
| 5 | 横向场景漏写 `;` 前缀 | "跟纵向一样写就行" | 纵向坐标取不到横向兄弟格，结果**静默为空/错值** | 🔵 FR 帮助（横向必须末参 `false` ↔ 展开成 `[;X:N]`）+ 🟡 语料两种写法并存 |
| 6 | 坐标写在**不扩展**的格里（`<Expand/>`） | "反正取到了值" | 该格本身不扩展 → 多值会被**逗号拼成一格**（本项目已实测，见 `docs/探索/图表与控件模型.md` §3.2 同类坑） | 🟢 已实测（`<Expand/>` 多值拼串） |
| 7 | `<Expand/>` + 层次坐标的组合 | — | 同上：坐标拿到数组但格子不扩展 → 只能得到一个拼接字符串 | 🟢 同上 |

**验收判据（写给实现者）**：
1. 层次坐标的返回值**可能是数组**，`SUM/COUNT/JOINARRAY` 能吃，直接放进单值格会**静默拼串**；
2. `C3` 与 `C3[!0]` **必须当成两件事**测——同一个格改一个字符，导出结果就该不同（不同=对，相同=踩了 #1）；
3. 第一行/第一列/第一组的边界必须**单独造数据测**（`&A3 = 1` 的分支在真实数据里很容易永远走不到）；
4. 横向扩展的场景必须**单独造一张**，别只测纵向。

---

## 7. 给实现者的最小可用清单

要把「层次坐标」做成命令/能力，**至少覆盖这 5 个**（按语料频次排序）：

1. `Cell[!0]` + `Cell[!0]A{条件}` —— 全部 + 过滤（33 + 32 处，最多）
2. `Cell[Cell:N]` —— 相对偏移（纵向 30 处、横向 14 处）
3. `&Cell` / `$Cell` —— 序号 / 当前值（67 + 24 处）
4. `Cell[!0;!0]` —— 交叉表整块（14 处）
5. 上面 7 个函数里**先做 `MOM`（环比）、`PROPORTION`（占比）、`SORT`（排名）、`LAYERTOTAL`（累计）**
   —— 这四个是业务高频，且展开式都已给出，实现成本极低

**不要做**：`Cell[A3:!-1]`（🔴 语义未证实）、`A` 后缀的精确语义（🔴 未查清，**照抄语料即可，不要自己发挥**）。
